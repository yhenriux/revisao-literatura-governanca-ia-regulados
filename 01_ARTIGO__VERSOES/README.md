# Artefatos do artigo

Esta pasta contém somente versões oficiais ou historicamente necessárias do manuscrito.

## Qual arquivo usar?

| Necessidade | Arquivo |
|---|---|
| Enviar aos professores ou ler | `ARTIGO__T-v1__LEITURA.pdf` |
| Editar o manuscrito | `ARTIGO__T-v1__EDICAO.docx` |
| Revisar alterações | `ARTIGO__T-v1__REDLINE.docx` |
| Consultar o manuscrito original | `ARTIGO__T-v0__FONTE.docx` ou `ARTIGO__T-v0__LEITURA.pdf` |
| Auditar o estado anterior à correção final | arquivos `ARTIGO__T-v1-pre-auditoria__*` |

## Regra de preservação

Arquivos históricos documentam a proveniência editorial. Não sobrescreva, renomeie ou exclua um artefato publicado. Novos marcos devem ser registrados na política de versionamento, no changelog e no Git.

Renders PNG, caches, logs locais e exportações intermediárias não pertencem a esta pasta.
