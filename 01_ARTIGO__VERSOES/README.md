# Artefatos do artigo

Esta pasta contém somente versões oficiais ou historicamente necessárias do manuscrito.

## Qual arquivo usar?

| Necessidade | Arquivo |
|---|---|
| Enviar aos professores ou ler | `Artigo_Governanca_Conversacional_v1_FINAL_PARA_LEITURA.pdf` |
| Editar o manuscrito | `Artigo_Governanca_Conversacional_v1_EDITAVEL.docx` |
| Revisar alterações | `Artigo_Governanca_Conversacional_v1_COM_ALTERACOES.docx` |
| Consultar o manuscrito original | `Artigo_Governanca_Conversacional_v0_ORIGINAL.docx` ou `.pdf` |
| Auditar o estado anterior à correção final | arquivos `Artigo_Governanca_Conversacional_v1_PRE_AUDITORIA_*` |

## Regra de preservação

Arquivos históricos documentam a proveniência editorial. Não sobrescreva, renomeie ou exclua um artefato publicado. Novos marcos devem ser registrados na política de versionamento, no changelog e no Git.

Renders PNG, caches, logs locais e exportações intermediárias não pertencem a esta pasta.
