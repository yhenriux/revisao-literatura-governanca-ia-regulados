# Visão geral do projeto

## Objeto

Revisão sistemática da literatura sobre mecanismos de governança conversacional em sistemas baseados em Modelos de Linguagem de Grande Escala implantados em ambientes regulados.

## Problema científico

A literatura distribui mecanismos relevantes entre governança de IA, Responsible AI, accountability algorítmica, auditoria, explicabilidade, interação humano-IA, LLMOps e estudos setoriais. O projeto investiga como essas perspectivas se integram no controle, monitoramento, justificação e correção de sistemas conversacionais.

## Contribuição central

Modelo Conceitual Integrado de Governança Conversacional composto por cinco camadas interdependentes:

1. técnica;
2. interacional;
3. organizacional;
4. regulatória;
5. evolutiva.

## Autoridade dos números na revisão v1

A versão v0 do artigo é a fonte de verdade editorial. Permanecem invariantes:

- 407 estudos únicos avaliados em texto completo;
- 177 estudos no corpus analítico;
- 23 evidências centrais;
- 154 evidências de apoio;
- 112 referências fundacionais ou contextuais;
- 118 estudos excluídos.

Documentos de pipeline podem representar outros momentos, universos ou estados operacionais. Essa diferença não autoriza a alteração silenciosa dos números do manuscrito.

## Estado da versão v1

A v1 responde ao parecer de Mauricio B. Almeida. O artigo foi reorganizado para conduzir o leitor por problema, lacuna, método, evidências, modelo e contribuição. Detalhes de software foram deslocados para documentação e suplemento.
