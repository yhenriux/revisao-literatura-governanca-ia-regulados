# Como colaborar no projeto

## Antes de alterar

1. Leia o `README.md` e identifique o artefato correto.
2. Consulte a política de versionamento e o registro de decisões.
3. Verifique `git status` para não misturar trabalho de outra pessoa.

## Como escrever uma mudança clara

- Explique o efeito da mudança, não apenas o arquivo alterado.
- Preserve números, evidências e referências da v0, salvo decisão documentada.
- Diferencie resultado da revisão de proposição autoral.
- Use português claro, títulos orientados à tarefa e nomes estáveis.

## Antes de entregar

- Confira se o manuscrito limpo e a redline continuam equivalentes após aceitar as alterações.
- Renderize DOCX/PDF quando houver mudança de layout.
- Atualize changelog, inventário ou decisão somente quando o estado realmente mudar.
- Remova intermediários locais; não os adicione ao Git.
- Informe no commit o efeito da mudança usando os prefixos definidos em `VERSIONING_POLICY.md`.
